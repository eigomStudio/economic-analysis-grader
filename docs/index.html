選んだファイルはこのPC / Mac の中だけで処理されます。インターネット上のサーバーには送信されません。
※フォルダやファイルを選ぶとき、ブラウザの確認画面に「アップロード」と表示されることがありますが、これはブラウザがファイル選択のときに必ず使う決まった表現です。実際には、ファイルはどこにも送信されません。

本当に送信されていないことを確認するには 採点の前に、キーボードのF12キー(Macは Option+Command+I)で開発者ツールを開き、「ネットワーク」のタブを表示してください。「採点する」を押しても、通信の一覧が増えなければ、ファイルは外に出ていません(ページを開いたときの、プログラムの読み込みの通信だけが表示されます)。
